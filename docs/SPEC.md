# MavLang — языковая спецификация v0.5

MavLang (расширение `.mavl`) — учебный low-level язык в духе Rust/Zig.
Компилятор `mavc` транспиллирует `.mavl` в Rust (`intRs/`) и собирает через `cargo`/`rustc` в нативный `.exe`.

---

## 1. Общие сведения

### 1.1 Цель языка
Максимально простой синтаксис,close к Rust, но без излишнегоью complex borrow-checker (в v0.5 borrow-checking delegated to `rustc`). Цель — быстро писать низкоуровневый код, который компилируется в быстрый нативный бинарь.

### 1.2 Компиляция
```
source/main.mavl  ──mavc──►  intRs/src/main.rs  ──cargo/rustc──►  target/debug/mavapp.exe
```
- Транспиляция построчная: одна строка `.mavl` ≈ одна строка `.rs`.
- Ошибки `rustc` маппятся обратно в строки `source/*.mavl`.
- Поддерживается несколько файлов: все `source/*.mavl` склеиваются, `main.mavl` первым.

### 1.3 Файл проекта
```
myapp/
  source/*.mavl      исходники (обязателен source/main.mavl)
  intRs/             Cargo.toml + src/main.rs (генерируется, не править вручную)
  target/debug/      готовые .exe/.dll
  target/release/    то же после --release
  mavlang.toml       (опц.) [deps] — зависимости крейтов
```

## 2. Лексика и синтаксис

### 2.1 Комментарии
- `//` — однострочный комментарий до конца строки.
- Блочных комментариев `/* */` нет.

### 2.2 Идентификаторы
- Начинаются с буквы или `_`, содержат буквы, цифры, `_`.
- Регистрозависимы.
- Зарезервированы: `fn`, `let`, `mut`, `if`, `else`, `while`, `for`, `in`, `return`, `struct`, `enum`, `impl`, `match`, `use`, `pub`, `const`, `unsafe`, `as`, `is`, `loop`, `break`, `continue`, `true`, `false`, `borrow`, `arena`, `manual`.

### 2.3 Литералы
- Целые: `5`, `-3`, `0xFF` (в текущей версии транспилятор передаёт их как есть в Rust, так что hex/бинарные литералы работают если валидны в Rust).
- Строки: `"hello"`, `'a'` (передаются как есть).
- Булевы: `true`, `false`.

### 2.4 Пробелы и переносы
- Точка с запятой `;` обязательна в конце стейтментов.
- `{ }` блоки — без точки с запятой после закрывающей скобки.
- Переносы строк не имеют значения внутри `{ }`.

## 3. Типы данных

| Тип | Описание | Пример |
|-----|----------|--------|
| `i32` | 32-битное целое со знаком | `let x: i32 = 5;` |
| `u32` | 32-битное целое без знака | |
| `i64` | 64-битное целое со знаком | |
| `u64` | 64-битное целое без знака | |
| `f32` | 32-битное число с плавающей точкой | |
| `f64` | 64-битное число с плавающей точкой | |
| `bool` | `true` / `false` | |
| `char` | один символ | |
| `String` | строка в куче (владение) | |
| `&str` | срез строки (заимствование) | |
| `Vec<T>` | динамический массив | `Vec<i32>` |

Массивы фиксированного размера: `[T; N]` (например `[i32; 3]`), передаются как есть в Rust.

## 4. Объявления

### 3.1 Функции
```rust
fn имя(параметры) -> возвращаемый_тип {
    тело;
    return значение;
}
```
- `fn main()` — обязательная точка входа.
- Параметры: `имя: тип`.
- Если нет возврата — тип можно опустить (транспилятор считает `()`, но для чистоты лучше писать `-> ()` или не указывать, если тело заканчивается выражением без `return`).
- `return` опционален, если последнее выражение функции — возвращаемое значение.

### 3.2 Переменные
```rust
let x: i32 = 5;        // неизменяемая
let mut y = 10;        // изменяемая, тип выводится
```

### 3.3 Структуры
```rust
struct Точка {
    x: i32,
    y: i32,
}
```

### 3.4 Перечисления
```rust
enum Направление {
    Вверх,
    Вниз,
}
```

### 3.5 Реализация методов
```rust
impl Точка {
    fn новая() -> Точка {
        return Точка { x: 0, y: 0 };
    }
}
```

## 5. Стандартная библиотека (встроенные функции)

Все функции ниже доступны **без импортов**. Транспилируются в вызовы стандартной библиотеки Rust.

| Функция | Что делает | Тип результата | Пример |
|---------|-----------|----------------|--------|
| `print(x)` | Печать в stdout | — | `print(x); print("hi");` |
| `input(prompt)` | Строка из stdin с промптом | `String` | `let n = input("имя? ");` |
| `len(x)` | Длина строки/массива/вектора | `usize` | `len(s);` `len(v);` |
| `read_file(path)` | Весь файл в строку | `String` | `read_file("a.txt")` |
| `write_file(path, data)` | Записать строку в файл | — | `write_file("o.txt", "hi");` |
| `append_file(path, data)` | Дописать в конец файла | — | `append_file("log.txt", "строка\n");` |
| `split(s, delim)` | Разбить строку на вектор | `Vec<String>` | `split("a,b", ",")` |
| `lines(s)` | Разбить по строкам на вектор | `Vec<String>` | `lines(read_file("a.txt"))` |
| `join(v, delim)` | Склеить вектор в строку | `String` | `join(v, ",")` |
| `trim(s)` | Обрезать пробелы по краям | `String` | `trim("  hi  ")` |
| `upper(s)` | Верхний регистр | `String` | `upper("abc")` → `"ABC"` |
| `lower(s)` | Нижний регистр | `String` | `lower("ABC")` → `"abc"` |
| `capitalize(s)` | Первая буква заглавная | `String` | `capitalize("hi")` → `"Hi"` |
| `to_int(s)` | Строка в i32 | `i32` | `to_int("42")` |
| `sleep(ms)` | Пауза в миллисекундах | — | `sleep(100);` |
| `args()` | Аргументы командной строки | `Vec<String>` | `args()` |
| `arg(i)` | i-й аргумент или `""` | `String` | `arg(1);` (0 — имя программы) |
| `contains(s, sub)` | Есть ли подстрока | `bool` | `contains("abc", "b")` |
| `check(условие)` | assert (для тестов) | — | `check(1 + 1 == 2);` |

### Примечания по типам возвращаемых значений
- Функции возвращающие `Vec<String>` (`split`, `lines`, `args`) — при передаче в `print()` автоматически форматируются через `{:?}` (отладочный вывод).
- Функции возвращающие `String` или `i32`/`bool` — через `{}`.

## 6. Режимы памяти (`--mem`)

Компилятор поддерживает три режима, выбираемых флагом `--mem`:

| Режим | Описание |
|-------|----------|
| `borrow` (default) | Обычные `& / &mut`, проверки borrow-checker от `rustc`. |
| `arena` | Заглушка. В будущем — bump-аллокатор. |
| `manual` | Разрешён `unsafe` и сырые указатели (`*mut T`, `*const T`). |

Пример unsafe:
```rust
fn main() {
    let mut a = [10, 20, 30];
    let p: *mut i32 = a.as_mut_ptr();
    unsafe {
        *p.offset(1) = 99;
    }
    print(a[1]);  // 99
}
```

## 7. Множество файлов

Все `source/*.mavl` склеиваются в один `intRs/src/main.rs`:
1. Сначала `main.mavl` (если есть).
2. Остальные по алфавиту имён файлов.
3. Каждый файл отделяется комментарием `// <имя_файла>`.

Ошибки компиляции маппятся обратно в соответствующий `source/*.mavl` с правильным номером строки.

## 8. Зависимости крейтов (`mavlang.toml`)

Опциональный файл в корне проекта:

```toml
[deps]
egui = "0.28"
serde = "1"
```

`mavc build` читает его и добавляет секцию `[dependencies]` в `intRs/Cargo.toml`. Поля `name` и `edition` не трогаются. Если файла нет — зависимости не добавляются.

## 9. CLI компилятора `mavc`

```
mavc check [--mem=borrow|arena|manual]
mavc build [--release] [--mem=...]
mavc run   [--release] [--mem=...]
mavc clean
mavc lsp   (мини LSP-сервер: диагностика, completion, hover по stdio)
mavc watch [--release] [--mem=...]  (автосборка при изменении source/)
```

- `check` — только проверка синтаксиса и транспиляция без вызова cargo.
- `build` — транспиляция + `cargo build`, бинарник копируется в `target/debug/` или `target/release/`.
- `run` — сборка и немедленный запуск.
- `clean` — удаление целей сборки.
- `lsp` — запуск Language Server Protocol сервера для редакторов.
- `watch` — следит за `source/`, пересобирает при изменении.

## 10. Ошибки и отладка

- Ошибки синтаксиса MavLang (отсутствие `fn main`, дисбаланс `{ }`) сообщаются как `MavLang error in source/ИМЯ: строка`.
- Ошибки `rustc` (`main.rs:NN`) маппятся обратно в `source/ИМЯ:MM` (с учётом шапки транспиляции).
- `intRs/src/main.rs` — сгенерированный Rust-код, можно смотреть для отладки.
